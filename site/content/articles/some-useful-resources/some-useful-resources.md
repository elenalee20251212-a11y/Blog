## Prompt

请全面、反复多轮搜索网上公开的代数方向一流数学家的网课，尽量完整。不要只搜目前已经覆盖到的少数方向；没有搜到的领域要继续补充，已经搜过的领域也要继续补漏。

只要能够直接观看访问的网课录像, 授课人本身需要是一流数学家。

整理时按以下层级分类：

- 基础课：第一门或核心研究生基础课程的水平 ( 比如说古典ag, gtm52第二章对应的scheme theory, 第三章对应的上同调 ) 。
- 进阶 / 专题课：second course、过渡课程，或者某个小方向的入门专题课程。
- 小方向专业课 / 深入专题：直接进入更深入的专门方向, 一般需要非常熟悉前面对应的基础课内容。

每个层级再分成长课程和短课程。

最终不要做成表格，使用分层标题和清单。每条写成：**授课人 - 课程名称**｜课程总量｜视频链接｜（如果可能有歧义, 再用几个词注明课程内容）。

你最好通过遍历机构课程档案来查询, 以及要注意解决非标准标题的问题.

**本版追加要求：**以完全相同的标准加入代数拓扑、同伦论及其直接相关的稳定同伦、等变/整体同伦、高阶范畴、代数 K 理论、THH/TC、motivic homotopy 等；除按领域名检索外，还按一流数学家姓名反查个人频道、机构录像库、YouTube/Bilibili 非官方搬运与镜像。只保留当前能够直接访问到录像或逐讲录像入口的课程；已失效录像、纯讲义课程、只有课程公告而无公开视频者不列入。

## 核验说明

- 优先给官方课程页、学校/研究所录像档案、授课人个人页；同时保留已核实的 YouTube/Bilibili 非官方镜像，尤其用于官方链接不稳定或标题不标准的课程。
- “课程总量”尽量按当前实际可见录像计数；若课程编号、官方课程讲次与现存录像数不同，会同时注明。
- “长课程 / 短课程”按课程形态和原稿习惯划分，不机械以某个固定讲数为唯一界线。
- 同一课程若有课程总页和直接公开视频/镜像，会尽量同时给出。
- **检索规则：**同时执行“理论领域树 × 数学对象树 × 一流数学家名单 × 授课人 teaching-history 闭包 × A/B/I/II/C 课程序列闭包 × 机构逐年档案遍历 × 非英语/非官方镜像反查”，并读取 syllabus/逐讲标题处理非标准课程名。
- **必须当前仍可观看：**课程页历史上写有 Videos 但实际端点已失效者不列入；纯讲义或明确未录像的著名课程同样不用于“填空”。
- **本文件是阶段性成果，不代表检索终止。**本轮重点补入由上述系统性方法修正直接发现、且目前能够落实到课程/录像入口的长课程。
- **本轮范围：只新增、补漏与复核长课程。**短课程部分为保持原稿结构而原样保留，但本轮没有重新逐条复核短课程，因此不以短课程部分作为本轮链接状态声明。
- **本轮视频链接处理：**凡机构页只笼统写有 Videos/Recording，而能定位到官方播放列表或逐讲录像档案者，补上明确的录像入口；历史链接若现已返回错误、登录墙、空文件夹，或只剩讲义，则不作为本轮新增课程。
- **语言标注：**授课语言为英语或中文时不额外标注；已核实为其他语言的课程在条目末尾显式注明，例如“（法语）”。
- **受限录像：**需要密码、机构授权或联系授课人后才能看的完整长课，不进入主清单；仅放在文末附录，和“当前公开直看”的课程严格分开。
- **Derived AG 特别规则：**该方向较新且完整长录像稀缺，因此优先近 5–10 年、尤其 2020 年后的系统课程；讲者门槛可从“公认一流”适度放宽到“在 DAG/derived geometry 方向学术地位很不错且有实质影响力”，其他方向仍保持原 Prompt 的一流学者标准。
