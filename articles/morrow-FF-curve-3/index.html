3. 向量丛 (VECTOR BUNDLES)

本节主要介绍 Fargues–Fontaine 曲线上的向量丛与 ppp-进 Galois 表示以及 ppp-进 Hodge 理论中出现的各类线性代数范畴之间的联系。

3.1. Harder–Narasimhan 理论

  • 经典曲线上的 slope 理论：
    设 XXX 是一个黎曼曲面或代数闭域上的光滑射影曲线。对于 XXX 上的任意向量丛 EEE，我们可以关联两个基本不变量：

    • 秩 (Rank)：rk E∈N\text{rk } E \in \mathbb{N}rk E∈N
    • 度 (Degree)：deg E∈Z\text{deg } E \in \mathbb{Z}deg E∈Z，定义为其行列式线丛的度。若将线丛 LLL 对应于 Weil 除子 ∑x∈Xnx[x]\sum_{x \in X} n_x [x]∑x∈X​nx​[x]，则 deg L:=∑x∈Xnx\text{deg } L := \sum_{x \in X} n_xdeg L:=∑x∈X​nx​。

    由此定义 EEE 的第三个不变量，即 斜率 (slope)：
    μ(E):=deg Erk E∈Q\mu(E) := \frac{\text{deg } E}{\text{rk } E} \in \mathbb{Q}μ(E):=rk Edeg E​∈Q
    若对于 EEE 的每一个子丛 E′⊆EE' \subseteq EE′⊆E（此处指局部直和项），均满足 μ(E′)≤μ(E)\mu(E') \le \mu(E)μ(E′)≤μ(E)，则称 EEE 是半稳定的 (semi-stable)。

with the following two properties：

  • the quotient bundle Ei/Ei−1E_i/E_{i-1}Ei​/Ei−1​ is semi-stable for each i=1,…,mi = 1, \dots, mi=1,…,m, and
  • μ(E1/E0)>⋯>μ(Em/Em−1)\mu(E_1/E_0) > \cdots > \mu(E_m/E_{m-1})μ(E1​/E0​)>⋯>μ(Em​/Em−1​).

Harder-Narasimhan 理论的公理化推广：
设 E\mathcal{E}E 为一个范畴，每个对象 E∈EE \in \mathcal{E}E∈E 在同构意义下有两个关联的不变量 rk E∈N\text{rk } E \in \mathbb{N}rk E∈N 和 deg E∈Z\text{deg } E \in \mathbb{Z}deg E∈Z，并定义斜率为 μ(E):=deg E/rk E\mu(E) := \text{deg } E / \text{rk } Eμ(E):=deg E/rk E。为使该理论有效，需满足以下假设：

在这些假设下，E\mathcal{E}E 中的任何对象都拥有唯一的 Harder–Narasimhan 过滤。

过滤晶体范畴

上述单方面的嵌入（仅带过滤或仅带 Frobenius）并非满忠实的，也未完全确定其像。Fontaine 通过同时考虑过滤和 Frobenius 结构克服了这一困难。
