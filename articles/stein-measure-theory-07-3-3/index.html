3.3 Peano 映射的构造

下面给出的特殊二进对应，为描绘 Peano 曲线的近似曲线提供了逐步构造方法。构造的主要思路是：在第 kkk 代中，从一个四分区间移动到下一个四分区间时，相应地从一个第 kkk 代二进正方形移动到另一个与之有公共边的第 kkk 代正方形。

更确切地说，若同一代的两个四分区间有公共点，就称它们相邻；若同一代的两个正方形有公共边，就称它们相邻。

引理 3.7：存在唯一的二进对应 Φ\PhiΦ，使得：

(i) 若 III 和 JJJ 是同一代中相邻的两个区间，则 Φ(I)\Phi(I)Φ(I) 与 Φ(J)\Phi(J)Φ(J) 是同一代中相邻的两个正方形。

(ii) 在第 kkk 代中，若 I−I_-I−​ 是最左侧区间、I+I_+I+​ 是最右侧区间，则 Φ(I−)\Phi(I_-)Φ(I−​) 是左下角正方形，Φ(I+)\Phi(I_+)Φ(I+​) 是右下角正方形。
